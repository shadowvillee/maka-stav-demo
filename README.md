# MAKA-STAV — ukázkový web

Statická ukázka webu pro rekonstrukce bytů a koupelen.

**Živá ukázka:** https://shadowvillee.github.io/maka-stav-demo/

Animovaný příběh, galerie a katalog služeb jsou součástí této ukázky. Fotografie v galerii jsou ilustrační; skutečné realizace zatím nejsou zveřejněny. Kontaktní formulář připraví e-mail v poštovní aplikaci uživatele a nic neodesílá na server.

Zdrojové soubory jsou v kořeni repozitáře. GitHub Pages je publikují z větve `main`.
